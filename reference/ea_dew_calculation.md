# Actual vapour pressure (ea) derived from dewpoint temperature

Actual vapour pressure (ea) derived from dewpoint temperature

## Usage

``` r
ea_dew_calculation(tdew)
```

## Arguments

- tdew:

  A dataframe with dewpoint temperature (Celsius).

## Value

Returns a data.frame object with the ea from dewpoint data.
