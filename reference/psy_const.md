# Psychrometric constant

Psychrometric constant (kPa/Celsius) is calculated in this function.

## Usage

``` r
psy_const(Patm)
```

## Arguments

- Patm:

  Atmospheric pressure (kPa)

## Value

A data.frame object with the psychrometric constant calculated.
