# Localization of the automatic weather station of INMET

Function to see the localization of the automatic weather station of
INMET.

## Usage

``` r
see_stations_info()
```

## Value

A data.frame with informations of OMM code, latitude, longitude and
altitude of all AWS stations available in INMET.
