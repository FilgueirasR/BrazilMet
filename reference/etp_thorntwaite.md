# Thorntwaite - Potential evapotranspiration

Thorntwaite - Potential evapotranspiration

## Usage

``` r
etp_thorntwaite(tmean)
```

## Arguments

- tmean:

  A dataframe with Mean monthly air temperature (Celsius)

## Value

Returns a data.frame object with the Thorntwaite ETp data
