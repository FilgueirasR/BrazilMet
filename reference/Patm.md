# Atmospheric pressure (Patm)

Atmospheric pressure (Patm)

## Usage

``` r
Patm(z)
```

## Arguments

- z:

  Elevation above sea level (m)

## Value

Returns a data.frame object with the atmospheric pressure calculated.
